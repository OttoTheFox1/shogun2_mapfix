# shogun2_mapfix
Fixes the issue with the Shogun 2 Morning Sun mod where the assets far east/west would disappear.

This has only been tested on Steam on Windows.

Instructions for installing: \
Download the dll from here. \
Navigate to your "Total War Shogun 2" directory in steamapps/common. \
Copy the downloaded dll into that directory and replace the old one. \
\
\
Testing that it works:
Launch the game with Morning Sun. \
Load a game with known missing assets (like a new Ming game). \
Navigate to a far west/east province and ensure all assets appear.
